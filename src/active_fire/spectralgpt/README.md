# About SpectralGPT

The content under this folder is a part of the SpectralGPT: Spectral Remote Sensing Foundation Model, provided by the [oficial repository](https://github.com/danfenghong/IEEE_TPAMI_SpectralGPT). We have done some modifications in the source code in order to fit ours experiments. For mor information about the SpectralGPT and for the the full source code One can rely in the following resources:

Article: [https://ieeexplore.ieee.org/document/10490262](https://ieeexplore.ieee.org/document/10490262)

Repository: [https://github.com/danfenghong/IEEE_TPAMI_SpectralGPT](https://github.com/danfenghong/IEEE_TPAMI_SpectralGPT)
